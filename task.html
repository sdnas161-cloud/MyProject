Task Management System

A web-based task management application developed using Python and Django for managing employees, assigning tasks, and tracking task status.

Project Overview

The Task Management System is a web application developed using Python and Django.

The system allows administrators to manage employees and assign tasks. Employees can view their assigned tasks and track the current status of each task.

The application provides a simple and organized interface for managing tasks and employee activities.

Key Features

Employee Management

Add and manage employee information.

Task Assignment

Assign tasks to employees and manage task details.

Task Tracking

Track task progress and completion status.

User Management

Manage users and provide controlled access.
