Task Management System

A responsive task management web application developed using Python and Django to manage employees, assign tasks and track task progress through an organized dashboard.

Full Stack Web Application
Python + Django Backend
MySQL Database

Project Overview

The Task Management System is a full-stack web application developed using Python and Django.

The application provides a structured platform for managing employees and assigning tasks. Administrators can manage employee information and create tasks for individual employees.

Employees can view their assigned tasks and monitor their current status, making it easier to organize daily work and track progress.

Key Features

Employee Management

Add, manage and organize employee information.

Task Assignment

Create and assign tasks to employees.

Task Tracking

Track task progress and completion status.

User Management

Provide controlled access for different users.

Technologies Used

Python Django HTML5 CSS3 Bootstrap JavaScript MySQL
